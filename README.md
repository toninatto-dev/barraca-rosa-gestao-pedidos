# A Barraca Rosa — Sistema de Gestão de Pedidos e Cardápio Digital

Projeto Integrador desenvolvido para otimização da gestão de atendimento, cardápio digital e fluxo de pedidos do trailer de lanches A Barraca Rosa.

---
* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide React
* **Backend & Banco de Dados:** Supabase (PostgreSQL + RLS + Authentication)
* **Hospedagem:** Vercel
